FYNA Designspråk
Designsystem · referanse for gjenbruk

Et rolig, nordisk designspråk — destillert til tokens du kan ta med videre.

Dette er retningslinjene bak FYNAs grensesnitt, samlet slik at de kan videreføres i et urelatert prosjekt. Selve siden følger systemet den beskriver. Kjernen — palett, typografi, spacing, flater og komponentoppskrifter — er produktnøytral; det domenespesifikke (kategorifarger, kart) er merket som eksempler. Klikk en verdi for å kopiere den.

01

Prinsipper

Uttrykket skal føles som et moderne digitalt produkt, ikke et administrasjonssystem. Kvaliteten kommer fra typografi, spacing, flater, hierarki og konsistens — ikke fra effekter.

Ledestjernen

Airbnbs varme og brukervennlighet møter Lumas moderne produktdesign, filtrert gjennom et rolig nordisk språk. Tidløst framfor trendy; troverdig framfor prangende.

Prioriter

Mye whitespace · få streker · tydelig typografisk hierarki · myke flater · subtil dybde · færre harde kontraster · små, presise detaljer · svært konsistente komponenter.

02

Fargepalett

Grønt er identitetsbærende, men skal ikke dominere. Store flater er hvite eller svært lyse; grønt reserveres for primærhandlinger, aktiv navigasjon, valgte states og små aksenter. Nøytralene er bevisst dratt mot grønt — ikke en rå grå.

Lys modus
Mørk modus
AA
Tilgjengelighet går foran. Tertiærtekst #89938D (3,2:1) og placeholder #929C96 (2,8:1) fra briefen brukes ikke som tekstfarger — de bryter WCAG AA. Sekundærnivået #5F6D65 (5,4:1) dekker metadata, labels og placeholder. #89938D kan brukes dekorativt (ikoner, streker).
03

Kategorifarger

Domenespesifikt for FYNA, men et nyttig mønster: et sett distinkte, dempede farger på lik metning, holdt utenfor temavariablene som datadrevne verdier. Fargen bæres av prikk/kant — teksten holder forgrunnsfargen, så kontrasten alltid er godkjent. Bytt hele settet for ditt eget domene.

04

Typografi

Én familie — Geist (fallback Inter/system-ui) — med Geist Mono til tall og tokens. Hierarkiet kommer fra størrelse, spacing og tone, ikke bare vekt. Overskrifter strammes med negativ letter-spacing; unngå for mange vekter.

05

Spacing

Én skala, gjennomgående. Unngå tilfeldige avstander (13, 18, 27 px). Seksjonsavstand 32–40 px; store seksjoner 48–64 px. La whitespace gjøre struktureringsjobben framfor streker.

06

Konsistent radius-system knyttet til elementtype — aldri tilfeldige verdier.

08

Knapper

Høyde 42 px (primær 44), radius 10, vekt 500. Ikke gjør alle knapper like viktige: én tydelig primærhandling, resten rolige. Rød brukes som outline, ikke fylt, med mindre handlingen krever sterk oppmerksomhet. FYNA bruker ofte helt runde knapper (999px) i verktøylinjer.

09

Chips & badges

Filter-pills er et bærende element: høyde 36, helt runde, hvit med kant, grønn når valgt. Badges er små og diskré (22 px), myk grønn framfor harde outlines.

10

Skjemafelt

Alle felt skal føles som en del av systemet, ikke browser-default. Høyde 46, radius 10, myk kant. Fokus: grønn kant + en 3 px ring på 12 % alpha. Label 6–8 px over feltet; 18–22 px mellom formgrupper.

Vises som overskrift på aktivitetskortet.
11

Kort & lister

Kort er den viktigste byggeklossen: hvit flate, hårfin kant (8 % blekk), radius 16, knapt synlig skygge. Ved hover heves kortet 1 px med en litt sterkere skygge. Lister skilles primært med whitespace; metadata er sekundær og handlinger dominerer aldri innholdet. Store paneler bruker radius 18 — ikke ramme inn hver interne seksjon.

12

Navigasjon

Svært ren header (64 px), nesten hvit med en hårfin bunnstrek og en nesten usynlig blur. Navigasjonselementer er runde (36 px). Aktiv tilstand: myk grønn flate og mørk grønn tekst — ingen tunge tabs eller rammer.

13

Bevegelse & fokus

Microinteractions er subtile: én felles overgang på 160 ms ease for bakgrunn, kant, farge, skygge og transform. Tillatt: translateY(-1px) ved hover. Ikke bounce, skalering, lange overganger eller glow.

Overgang

transition
transition:
  background-color 160ms ease,
  border-color     160ms ease,
  color            160ms ease,
  box-shadow       160ms ease,
  transform        160ms ease;

Synlig tastaturfokus

Alltid en synlig outline i tillegg til den myke ringen — den myke ringen alene er ikke nok som tastaturfokus. Tab deg til knappen:

:focus-visible
:focus-visible {
  outline: 2px solid var(--ring);
  outline-offset: 2px;
}
14

Ti regler

Sjekklisten som holder uttrykket konsistent. Bryt dem bare med god grunn.

Ikke bruk helt hvit bakgrunn på hele flaten — bruk den varme grunnflaten.
Ikke tegn rammer rundt alt; la whitespace strukturere.
Ikke bruk store skygger.
Ikke bruk gradients som hovedvirkemiddel.
Ikke gjør alle knapper visuelt like viktige.
Ikke gjør all tekst like mørk — bruk sekundærnivået.
Ikke bruk for mange font-vekter.
Ikke reduser whitespace for å presse inn mer.
Ikke introduser et enterprise-dashboard-uttrykk.
Ikke bruk tilfeldige verdier når en token finnes.
15

Lim inn i WordPress

Legg tokenene som CSS-variabler på en klasse rundt plugin-en din — .fyna-ui — i stedet for :root. Da arver komponentene systemet uten å kollidere med temaets egne variabler, og du slår om mørk modus ved å sette klassen på samme container. Ingen Tailwind eller shadcn nødvendig; ren CSS.

fyna-tokens.css
/* Scope alt til plugin-containeren for å unngå temakollisjon */
.fyna-ui {
  /* Flater */
  --bg: #f7f9f7;            /* grunnflate, aldri helhvit */
  --surface: #ffffff;      /* kort/paneler */
  --subtle: #f2f6f3;       /* ghost-hover, subtil flate */
  --soft: #e3f1ea;         /* myk grønn identitetsflate */
  /* Tekst (tertiær utelatt – bryter WCAG AA) */
  --ink: #17231d;          /* primærtekst */
  --ink-2: #5f6d65;        /* sekundær: metadata, labels, placeholder */
  /* Grønn – identitet, brukes sparsomt */
  --primary: #187a5a;
  --primary-hover: #126347;
  --primary-active: #0e513b;
  --on-primary: #ffffff;
  /* Linjer */
  --border: #dde5e0;
  --border-faint: rgba(23,35,29,.08);
  --hairline: rgba(23,35,29,.07);
  /* Semantisk (adskilt fra aksenten) */
  --warning: #b97e1f;
  --danger: #b42318;
  --danger-soft: #fef0ee;
  --ring: #187a5a;
  /* Radius */
  --r-control: 8px; --r-input: 10px; --r-inner: 12px;
  --r-card: 16px; --r-panel: 18px; --r-pill: 999px;
  /* Skygger – maks tre nivåer, knapt synlige */
  --shadow-sm: 0 1px 2px rgba(20,30,25,.04);
  --shadow-card: 0 1px 2px rgba(23,35,29,.025), 0 8px 30px rgba(23,35,29,.035);
  --shadow-float: 0 16px 40px rgba(20,30,25,.10);
  /* Type */
  --sans: "Geist", "Inter", system-ui, sans-serif;
  --mono: "Geist Mono", ui-monospace, Menlo, monospace;

  background: var(--bg);
  color: var(--ink);
  font-family: var(--sans);
  font-size: 15px;
  line-height: 1.55;
}

/* Primærknapp */
.fyna-ui .btn {
  height: 42px; padding: 0 18px; border-radius: var(--r-input);
  font-weight: 500; border: 1px solid transparent; cursor: pointer;
  transition: background-color 160ms ease, border-color 160ms ease,
              box-shadow 160ms ease, transform 160ms ease;
}
.fyna-ui .btn--primary { background: var(--primary); color: var(--on-primary); }
.fyna-ui .btn--primary:hover { background: var(--primary-hover); }
.fyna-ui .btn--secondary { background: var(--surface); border-color: var(--border); color: var(--ink); }
.fyna-ui .btn--ghost:hover { background: var(--subtle); }

/* Filter-pill */
.fyna-ui .chip {
  height: 36px; padding: 0 14px; border-radius: var(--r-pill);
  background: var(--surface); border: 1px solid var(--border);
  font-size: 14px; font-weight: 500; cursor: pointer;
}
.fyna-ui .chip[aria-pressed="true"] {
  background: var(--primary); border-color: var(--primary); color: var(--on-primary);
}

/* Kort */
.fyna-ui .card {
  background: var(--surface); border: 1px solid var(--border-faint);
  border-radius: var(--r-card); box-shadow: var(--shadow-card);
  transition: border-color 160ms ease, box-shadow 160ms ease, transform 160ms ease;
}
.fyna-ui .card:hover { box-shadow: var(--shadow-float); transform: translateY(-1px); }

/* Inputfelt */
.fyna-ui input, .fyna-ui textarea {
  height: 46px; padding: 0 14px; border-radius: var(--r-input);
  background: var(--surface); border: 1px solid var(--border);
  font-size: 15px; color: var(--ink);
}
.fyna-ui input:focus, .fyna-ui textarea:focus {
  outline: none; border-color: var(--primary);
  box-shadow: 0 0 0 3px color-mix(in oklab, var(--primary) 12%, transparent);
}

/* Synlig tastaturfokus – aldri usynlig */
.fyna-ui :focus-visible { outline: 2px solid var(--ring); outline-offset: 2px; }

Geist ligger på Google Fonts: <link href="https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600;700&family=Geist+Mono&display=swap" rel="stylesheet">. I en WP-plugin: enqueue den med wp_enqueue_style() framfor en rå <link>.
